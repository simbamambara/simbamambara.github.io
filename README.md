# Simbarashe Mambara Portfolio Website

This is a static personal portfolio website prepared for GitHub Pages.

## Files

- `index.html` — the website content.
- `styles.css` — the website styling.
- `assets/organic-digital-banner.png` — the original abstract image fallback.
- `assets/organic-digital-banner-960.webp`, `assets/organic-digital-banner-1440.webp`, and `assets/organic-digital-banner-1916.webp` — optimized responsive image versions.

## Responsive layout

The site is set up for laptop, tablet, and mobile screens.

Laptop and desktop screens use wider two-column sections and three-column background/project areas. Tablet screens reduce the container width and move grids to two or one columns as needed. Mobile screens use a single-column layout, smaller image height, horizontally scrollable navigation buttons, and a stronger overlay on the contact background so the text remains readable.

## Main customizations to make

In `index.html`, update:

- `Your Role / Field`
- the About paragraphs
- LinkedIn, Blog, GitHub, and Academia.com links
- Education
- Skills
- Research Interests
- Selected Work
- Projects
- Email
- Professional or institutional address

Use a professional or institutional address, not a private home address, unless you intentionally want it public.

## GitHub Pages

Upload these files to a GitHub repository. Keep `index.html`, `styles.css`, and the `assets` folder at the top level of the repository. Then enable GitHub Pages from the repository settings.
